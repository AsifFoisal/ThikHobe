# FixMate

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Customers seeking device and appliance repairs, technicians presenting repair services, and administrators overseeing the platform.

## Product Purpose

A complete frontend visual prototype of a repair service marketplace. Show service discovery, repair requests, job tracking, and pay-after-completion concepts through presentation screens.

## Capabilities and Constraints

Next.js App Router, TypeScript, Tailwind CSS, and Lucide icons. Public pages, customer/technician/admin dashboards, shared profile, authentication designs, payment result designs, and error screens. Static example content only. No working authentication, credential validation, API integration, mock backend, CRUD, payment processing, artificial notifications, or simulated workflows. Navigation and basic visual interactions are permitted. Latest user instructions supersede the functional requirements of the original brief.

## Brand Commitments

FixMate name with a tool-related logo. Exactly three core brand colors, reusable tokens, and one distinctive font excluding Inter and Space Grotesk. User delegates the visual direction. Use Impeccable and Ponytail throughout without compromising UI quality. Preserve completed work in subsequent stages.

## Evidence on Hand

A clean Next.js starter with Base UI, Lucide, and Tailwind installed. No existing FixMate implementation, customer evidence, business statistics, brand assets, or backend. Sample services, people, prices, and records may be authored and must be identifiable as examples.

## Product Principles

- Complete every requested presentation surface.
- Keep public and dashboard layouts distinct within one visual system.
- Reuse components and static content; keep code straightforward.
- Make the prototype responsive, legible, and accessible.

## Accessibility & Inclusion

Semantic landmarks, keyboard focus, accessible labels, readable contrast, reduced motion, mobile navigation, and responsive data presentation. Bengali-compatible font fallback.
